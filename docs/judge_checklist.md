# 评委验收清单

在线地址：`待 Railway 部署后回填`

建议使用无痕浏览器。全部样例为合成数据，不需要账号或本地服务。公共环境为共享实例，已有记录属于正常现象。

## 1. 可访问性与安全

- [ ] 打开在线地址，60 秒内出现“RFQ 询价分析与报价智能体”和评委演示指引。
- [ ] 首页有 Excel、PDF、正文、投毒邮件四个样例按钮。
- [ ] 无需登录本机、无需安装依赖、无需启动本地服务。
- [ ] 侧栏看不到“重置演示数据”，记忆网关看不到“模拟历史遗留投毒”。
- [ ] 页面、报错、下载文件中看不到 API Key、数据库密码、连接地址或管理员口令。
- [ ] 快速连续执行过多写操作时返回清晰的 429 提示，而不是 500。

## 2. RFQ 主流程

- [ ] 点击“Excel 样例”，等待完成后自动选中新的 RFQ。
  - 预期：状态为“待审批”；客户、币种、贸易术语、交期和付款信息可见。
- [ ] 在“报价与审批”展开物料识别。
  - 预期：Excel 多行物料被结构化；每行有内部 SKU、匹配方法、分数和来源。
- [ ] 查看争单优先、均衡、利润优先三档卡片。
  - 预期：显示三个数据分支、金额、毛利、赢单概率、期望毛利和 DIFF 统计。
- [ ] 修改一行价格，选择全部有效行后“批准并提交”。
  - 预期：整单 MERGE；已提交报价可见；可下载 Excel/PDF/HTML 和回复邮件。
- [ ] 新建另一单，只勾选前两行批准。
  - 预期：只 PICK 被选行，其余行不进入主线。
- [ ] 驳回一张待审批单。
  - 预期：状态变为已驳回，三个报价分支被丢弃。

## 3. 决策审计与重放

- [ ] 打开已处理 RFQ 的“决策审计”。
  - 预期：按顺序看到 intake、parse、normalize、price、risk、commit、render 等记录。
- [ ] 检查表格列和任一详情。
  - 预期：包含模型、提示词版本、规则版本、数据快照、记忆快照、证据、输出、置信度、耗时、token/成本和人工动作。
- [ ] 点击“重放并对比当前数据”。
  - 预期：使用报价时的快照重算；逐行显示当时与当前值；不覆盖原报价。

## 4. MemoryGate 投毒防护

- [ ] 点击“投毒邮件”，打开新 RFQ 的报价页。
  - 预期：隐藏指令、虚假 40% 折扣、Net 120 等被 block；报价出现 `prompt_injection` 高风险。
- [ ] 打开“记忆网关”。
  - 预期：正常料号映射和资质偏好位于 `inbox_<rfq>` 隔离分支，状态为待评审；危险声明不在队列中。
- [ ] 取消不希望采纳的项，批准其余项。
  - 预期：批准项以 T3 进入主线；响应显示 `pre_merge_*` 快照；被排除项标记 rejected。
- [ ] 尝试从“记忆版本”直接合并 `inbox_*`。
  - 预期：请求被拒绝，必须经过 MemoryGate 审批接口。
- [ ] 运行“扫描主线”。
  - 预期：返回“未发现问题”或列出带原因和受影响 RFQ 的发现；服务异常时给出 503/重试提示而非泄露堆栈。

## 5. 记忆版本控制

- [ ] 在“记忆版本”记录当前条目数，创建唯一快照名。
- [ ] 手工写入一条不含敏感声明的测试记忆。
  - 预期：条目数增加，记忆有 ID、类型、信任等级和来源。
- [ ] 回滚到刚才的快照。
  - 预期：测试记忆消失，主线恢复到快照状态。
- [ ] 对学习分支执行 DIFF，再选择合并或丢弃。
  - 预期：主线在人工决定前不受分支内容影响。

## 6. 规则沙盒与模型路由

- [ ] 在“规则沙盒”新建唯一分支，将 `target_margin` 改为 `0.26`。
- [ ] 查看 DIFF 并运行近期询价回测。
  - 预期：主线与分支的金额、期望毛利差异可见，主线尚未改变。
- [ ] MERGE 分支。
  - 预期：规则主线更新，合并动作写入审计；也可用另一分支验证丢弃不改变主线。
- [ ] 打开“模型路由”。
  - 预期：路由表显示任务对应 fast/strong/fallback 模型；统计显示调用数、token、成本、平均耗时和置信度。

## 7. 稳定性与交付核对

- [ ] 四封样例均能到达待审批状态或给出明确业务错误，无空白页、无未处理 500、无长时间无限等待。
- [ ] 浏览器刷新后已提交业务记录仍可查询；容器重启后已完成审计仍在 MatrixOne。
- [ ] Gitee README 包含问题、方案、技术栈、创新点、使用说明、验证结果、数据合规、已知限制和在线/视频链接。
- [ ] 三分钟视频使用 Railway 线上版本，时长不超过 3 分钟，不出现本地链接或密钥。
- [ ] 仓库未跟踪 `.env`、本地数据库、上传文件、输出文件、日志、缓存或密钥。

## 已知边界（不判为缺陷）

- 公共实例共享数据，其他评委的 RFQ 可能同时出现在列表中。
- 远程 LLM、MatrixOne、Memoria 有网络延迟，单封复杂样例通常需要 30–90 秒。
- 管理重置和遗留投毒注入默认关闭且隐藏，仅维护者可在临时开启开关后操作。
- 容器本地生成文件不跨重启持久化；数据库中的业务记录、审计和外部记忆不受影响。
