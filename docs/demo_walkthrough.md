# 三分钟演示 · 点击级操作台本

首页红框里的「评委演示指引」是给评委自助走的 6 步路径；录制视频时按本台本操作，顺序与红框有三处调整（见文末）。控件名称全部对应 `web/app.py` 中的真实文案。

## 录制前预热（不入镜）

1. 无痕窗口打开线上地址，确认侧边栏「后端组件状态」四行列表为 `DB: matrixone`、`VCS: matrixone`、`记忆: memoria`、`LLM: 开`。
2. 点一次「Excel 样例」和一次「投毒邮件」，等结果出来即可——目的是消除冷启动等待，不是正式录制。
3. 进「⑥ 规则沙盒」确认 `target_margin` 当前值为 `0.22`（决定旁白里的 26% 是否成立）。
4. 若首页红框是折叠的（已有历史单时会自动折叠），手动点开「评委演示指引（约 3 分钟）」。
5. 侧边栏「询价单」下拉先记下最新一单的 ID，录制时按 ID 确认自己看的是同一张单。

## 为什么录制顺序和红框不完全一样

红框是评委自助路径，编号 4→5→6 便于顺读；录制要照顾画面连贯：

1. **规则沙盒提前到投毒之前**：投毒样例会新建一张 RFQ 并切走侧边栏选中项，「③ 决策审计」「② 报价与审批」都会换成新单，先做完审计与规则沙盒更省事。
2. **记忆版本放到记忆网关之后**：先让「批准勾选项并合并」产生 `pre_merge_…` 快照，回滚画面才有对照物。
3. **模型路由放到最后**：它的两张表是静态概览，适合压在收尾关键词幕之前。

## 五个高频录制事故

| 现象 | 原因 | 对策 |
|---|---|---|
| 点完样例画面停在「① 接收询价」 | `st.rerun()` 回到默认页签 | 手动点页签后再开始念下一句 |
| 物料识别、MemoryGate 找不到 | expander 默认折叠 | 录制前先点开一次，或录完再用剪辑补 |
| 规则沙盒画面写 `aggressive` / `0.18` | 表单默认值 | 录制前把分支名与新值改好 |
| 提交后行数与改价对不上 | 只改了「改价」没看「采用」勾选 | PICK 必须先取消目标行的「采用」 |
| 侧边栏单号跳到旧单 | 刷新后默认选中列表第一项 | 用侧边栏下拉按 ID 重新选，画面里会出现切换动作，需重录 |
