# 三分钟演示视频脚本

录制环境：Railway 线上地址；浏览器无痕窗口；1920×1080；页面缩放 90%；提前处理好 Excel 与投毒样例，避免把模型等待时间录入成片。截图、地址栏和控制台不得出现密钥、连接串、管理员口令或个人信息。

## 录制前准备

1. 在 Railway 将 `ALLOW_ADMIN_RESET=true`，用管理模式 reset 一次；随后立即改回 `false` 并重新部署。
2. 无痕窗口打开公共链接，确认顶部有评委指引、四个样例按钮，侧栏没有“重置演示数据”。
3. 预先跑完 `Excel 样例` 与 `投毒邮件`；分别保留待审批状态和 MemoryGate 待评审队列。
4. 规则沙盒使用分支名 `video_margin`，目标毛利从 `0.22` 改到 `0.26`。
5. 浏览器仅保留演示页签，关闭通知，隐藏书签栏；准备一页架构图（可使用 README 架构）。

## 剪辑与验收

- 总时长控制在 2:55–3:00；模型等待用跳切，保留操作结果，不加速到无法阅读。
- 关键字幕：`Quote-as-Commit`、`MERGE / PICK`、`Decision Audit`、`MemoryGate`、`100% contained`。
- 只使用 Railway 域名，画面不得出现 `localhost`、本地 IDE、终端或本地文件路径。
- 旁白里的测试数必须和最终 README 一致；若最终测试数变化，录制前同步更新。
- 录制结束后把视频上传到可匿名访问的平台，并回填 README 的视频链接。
